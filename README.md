# MCPie Homebrew tap

Install the MCPie contributor CLI on Apple silicon or Intel macOS.

```sh
brew install mcpie-org/tap/mcpie
mcpie self-test --json
```

Run `brew upgrade mcpie-org/tap/mcpie` to update. See the
[contributor guide](https://mcpie.xyz/contribute#install) for setup, or
[download the macOS binary](https://downloads.mcpie.xyz/macos.html) to install directly.

The formula downloads a prebuilt executable and verifies its SHA-256 checksum.
